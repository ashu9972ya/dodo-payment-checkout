# Demo App

Merchant-style demo for the Dodo Checkout SDK.

## Run locally

From the repository root:

```bash
pnpm --filter demo dev
```

Runs at [http://localhost:3001](http://localhost:3001).

Requires the checkout app on port 3000.

## Responsibilities

- Buy button that opens checkout via the SDK
- Visible callback event log
- Test card reference list

See the root [README](../../README.md) and [docs/ARCHITECTURE.md](../../docs/ARCHITECTURE.md) for full documentation.
